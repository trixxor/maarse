# Må:rse user guide

Short pages in plain language, one for each thing you can do. Every page
says what it is, how to do it on the Android app and in the web client,
shows an example, and links to the
[Denmark simulator](https://trixxor.github.io/maarse/denmark/) so you can
watch it happen.

In the working copy of the browser simulator, open **Traffic** in the play bar
to inspect recent packets. Filter by type and select a row to pin the packet's
recorded hops. Use the slider or **Scenario events** menu to review an outage,
and **Live** to return to the current run. Try **Great Belt traffic demo** with
terrain disabled. [Traffic controls and limits](../denmark/README.md#traffic-on-the-map)

To see the real network, choose **Real network** at the top of the page. It
shows the nodes, live packets and open channels of the servers you list under
**Servers**, and you can step back up to 24 hours with the bar at the bottom.
Server operators opt in under **Settings** with **Share the public map**,
**Share live traffic** and **Public history**.
[Real network: setup and privacy](../denmark/README.md#real-network-setup-and-privacy)

With the updated site and collector, **Packets** shows verified announces even
from an Android **Phone node** connected only over TCP. In **Name and position**,
choose a sharing precision and grant location permission to place that node on
the public map. The PC web client's **Sharing in announces** setting serves the
same purpose. **Public channels** shows new messages from `public` and
automatically identified open channels when the collector enables sharing.
[Packet observers and public channels](../denmark/README.md#packet-observers-and-public-channels)
