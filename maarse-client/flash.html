Må:rse flasher

Install Må:rse firmware over USB from the browser. Works on blank boards and boards running other firmware. Needs Chrome or Edge on a computer.

This browser has no Web Serial. Use Chrome or Edge on Windows, macOS or Linux.

1. Board

2. Firmware file

3. Flash

  1. Close the Må:rse host, the web client and any other program that uses the board's port.
  2. Plug in the board and press Flash. Pick its port in the list.
  3. No port, or it fails to connect: hold BOOT (PRG), press and release RST, release BOOT, and try again.
  4. Connect with the web client over USB and choose your own Bluetooth code. Every new node has the code 123456.

3. Flash

  1. Close the Må:rse host, the web client and any other program that uses the board's port.
  2. Start the bootloader. Press the button and pick the board's port. The board restarts as a USB drive (e.g. XIAO-SENSOR). No port, or the drive does not appear: press reset twice quickly instead.
  3. Flash over USB. Press the button and pick the port again (the bootloader's port; it may have a new name). The firmware is sent over serial DFU, the same way the MeshCore and RNode flashers do it, and the board restarts by itself.
  4. Connect with the web client over USB and choose your own Bluetooth code. Every new node has the code 123456.
Other ways: the USB drive

With the bootloader started, the board is also a USB drive. Pick the drive, or save the file and drag it onto the drive yourself.
