Start · Tutorial and how-to

Get started

Three ways in. You do not need a radio for the first one.

TL;DR

Fastest: start a host on your PC and use its web client in the browser. It takes about 15 minutes, most of it the first build. With a radio: flash a board with the web flasher, then connect to it from the web client or the phone app.

working copy bench-tested on Heltec V4 and XIAO nRF52840. The steps below have not been re-run from a clean machine since they were written, so if one does not give the result described, that is a bug in this page.

Which way is yours?

  • A. PC hostNo hardware. Windows or Linux.
  • B. Flash a radio boardHeltec V4, XIAO nRF52840 and others.
  • C. Android phoneThe native app, with the host built in.
  • D. Run a serverDebian or Ubuntu, for others to connect to.

A. Run a host on your PC

You need: Windows or Linux, internet access, about 2 GB of free disk space for the build, and a recent Chrome or Edge.

  1. Install Rust from rustup.rs with the defaults. In a new terminal, cargo --version should print a version number.
  2. Get the code: 
    git clone https://github.com/trixxor/maarse.git
cd maarse
  3. Start the host. On Windows double-click scripts\start-host.bat. On Linux run ./scripts/start-host.sh. The first start builds the program, which takes a few minutes.
  4. Check: a console window shows log lines, and your browser opens http://127.0.0.1:8080 and connects by itself.
  5. Find your address. The web client shows a 16-byte address as 32 hexadecimal digits. Your host made it the first time it started and keeps it in the maarse-data folder.
You join the open backbone by default

A fresh host connects to the open backbone, a shared public server, so you can reach other people at once. Remove it under Settings if you want to stay off it. Treat it as public infrastructure: it is not your own mail server.

Settings for a host are changed in the web client under Settings and are stored in settings.txt.

The web flasher (nothing to install)

  1. Use Chrome or Edge on a computer and open flash.html: from your running host at http://127.0.0.1:8080/flash.html, or from the project's site.
  2. Choose your board and follow the page.
  3. ESP32-S3: connect by USB. If it will not connect, hold BOOT and press RST. Your identity, contacts and mailbox are kept unless you tick erase the whole flash.
  4. nRF52840: press Start bootloader, then Flash over USB. If that fails, double-press reset so a USB drive appears, and copy the .uf2 file onto it.

Check: the board reconnects and shows up in the web client over USB or Bluetooth, and the status page shows the firmware version.

To update a board that already runs Må:rse, use the Firmware page in the web client or the app (USB, Bluetooth or the network). Updates are signed: a board installs only an image for its own board, with a newer version, signed with its built-in release key. Updates over LoRa are shelved, because LoRa is too slow.

C. Android phone

The native app has the host built in, so it needs no PC. It connects to a radio over Bluetooth or USB, and to the open backbone over the internet by default.

Honest status

The app is verified in an emulator. Bluetooth mode on a real phone has not been tested, and some features are missing compared with the web client.

The web client and the Android app are kept level: every user-facing change is made in both. More on the apps and clients page.

D. Run a server

A maarse-server is a dedicated host for a VPS or any machine with an open port. Other hosts find each other through it, hosts behind NAT are relayed, it keeps mail copies, and an admin dashboard shows telemetry.

sudo bash scripts/install-server.sh

On Debian or Ubuntu this installs the server as a service and asks for the settings. Put HTTPS in front of the dashboard for public access.

Try two nodes on one computer

This is the one place where command-line options are the right tool: two hosts on one computer need different folders and ports. In a second terminal in the maarse folder:

cargo run --release -p maarse-host --bin maarse-host -- --data maarse-data-b --http 127.0.0.1:8081 --listen 127.0.0.1:4243 --peer 127.0.0.1:4242

Check: a second browser tab at http://127.0.0.1:8081 shows a different address, and within seconds the first node appears there as a contact. Send hello from the second to the first. It appears in the first client, and a delivered mark appears in the second. That mark is the end-to-end acknowledgement: the other node decrypted the message.

Build the firmware yourself

Windows:

.\scripts\build-firmware.ps1 <board> -Flash

Linux:

./scripts/build-firmware.sh <board> flash
  • nRF52840: the script makes dist/maarse-<board>.uf2. Double-click the board's reset button, drag the file onto the USB drive that appears, then wait about a minute for USB to come back. If it has not after two minutes, or with older firmware, press reset once.
  • ESP32-S3: the first run installs Espressif's toolchain (espup) and espflash, which takes several minutes. The port must be free, so stop any host that uses the board as its modem first.

Radio settings and limits

Every Må:rse node uses 869.525 MHz in the EU band 869.4–869.65 MHz, with the same spreading factor and settings across the whole network. The firmware enforces the duty cycle (at most 10 % of the time) and listens before it talks. A node on another band or setting cannot talk to the rest of the network.
