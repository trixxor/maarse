Reference

Glossary

The words this handbook uses, in plain language.

TL;DR

Short definitions, in alphabetical order. A term is defined once here and used the same way everywhere else.

Address
16 bytes that identify a node. It is a hash of the node's public keys, so it is the same over radio, TCP and the internet.
Airtime
Time spent transmitting. It is the scarce resource of a LoRa mesh, shared by everyone and legally limited.
Anchor
A fixed repeater that also splits a long route into legs, so a route may be longer than 12 hops. A host or server that is always online is an anchor by default.
Announce
A signed message in which a node tells the network that it exists. It carries a small proof-of-work stamp.
Auto
A role for handhelds: a client while a repeater or anchor is heard, a relay after 2 minutes without one.
Backbone
TCP and UDP links between hosts that join separate radio areas into one network.
Carry
When no route exists, a handheld keeps the message and hands it to people it meets, until it reaches the recipient.
Channel
A group conversation protected by a shared key. public and #hashtag channels have keys derived from the name, so anyone can read them.
Client node
A node that sends and receives its own messages and never forwards for others. See Client node.
Companion protocol
The protocol a client uses to talk to a host or to a single radio: over USB serial, Bluetooth or WebSocket.
DHT (distributed hash table)
A lookup table shared across the internet hosts, with no central server. A host uses it to find which host can reach an address.
Duty cycle
The legal limit on how much of the time a device may transmit. In the band Må:rse uses, a device may transmit up to 10 % of the time.
Edge bridge
A relay that hears a repeater while a neighbour does not: the group's way into the repeater network.
Flood
Every node that hears a packet repeats it once. Simple and robust, but expensive in airtime.
Hop
One radio jump between two nodes.
Host
A program (maarse-host or maarse-server) that is a node itself and also a gateway between radios, the backbone and clients. It also keeps a post office.
LoRa
A long-range, low-power radio technique. Slow, a few hundred bytes per second, but it reaches kilometres.
Mailbox
Where mail waits for someone who is offline: a post office on a host, or a small flash area on a radio board for mail addressed to itself.
Path
A known list of repeaters to follow from sender to recipient. Messages along a path are source-routed.
Path request
The small flooded packet that discovers a path. Repeaters add themselves to it as it passes.
Post office
A host that keeps messages for people who are offline and delivers them when they come back. Mail is kept for 7 days, up to 100 messages per recipient.
Ratchet
The forward-secrecy mechanism: the keys for each message are new and are deleted after use, so a leaked key does not open old messages. A draft, not externally reviewed.
Recipe
The small program a sensor node runs, made in the designer from sentences like "when Temperature is below 10 °C, send an alarm".
Region
A name such as nordjylland that keeps a channel local: repeaters forward a regional channel only if they serve the region.
Relay
A handheld that forwards for others when it hears no repeater, for up to 4 hops.
Repeater
A fixed node that passes messages on.
Role
What a node does with other people's traffic: client, relay, repeater or anchor.
Safety number
A 60-digit number two people can compare to check that nobody is between them.
Seal
The encryption wrapped around a direct message. The static seal costs 64 bytes, the ratchet frame 69, the compact frame 22.
Server
maarse-server: a host built for the internet that is a DHT node, relays hosts behind NAT and keeps mail copies. See Server.
SNR
Signal-to-noise ratio, a measure of how well a packet was heard.
Spreading factor (SF)
LoRa's speed and range dial. Each step up reaches further but takes about twice as long per packet.
Stamp
A small proof of work attached to announces and requests. It costs the sender a little computation, which makes spam expensive.
Trunk
A long-distance LoRa link with directional antennas between two hosts, used as a backup when the internet is down. It uses the same frequency and settings as everything else.
Source: README glossary and the protocol specification.
