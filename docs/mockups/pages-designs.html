Pages: browser and three designs

The browser on the PC host. Today the browser is locked to 860 px and the page to 720 px, so it sits as a narrow strip in the middle. Proposal: the toolbar runs across the whole top of the pane, and the page fills the rest. The page decides how it uses the room: a newspaper sets columns, teletext sets its 40×25 grid and scales it to fit, plain text stays plain. A page with no layout of its own keeps a comfortable reading width (about 75 characters), so a plain text page never becomes one endless line.

F · Locked pages. A page (or a whole folder of pages and pictures) that only some people can open. The lock is written in the .mu file itself, like everything else, but it is the host that keeps it: the host reads the lock lines before it answers, and someone not on the list never gets the page at all. Nobody can fake who they are: a page request is a sealed message signed with the sender's own key, and the address is the fingerprint of that key (their certificate, in effect).

How the host keeps the lock

  
    
    
  1. The request is signed. A page request is a sealed message: only the host can read it, and only the sender's own key can have made it. The address is the fingerprint of that key, so it cannot be borrowed.
    2. 
    
  2. The host checks before it answers. It reads the @allow lines of the page (or of the folder's index.mu, which covers every page and picture in the folder) and compares the sender. A linked device counts as its person.
    3. 
    
  3. On the list: the page goes out sealed. Encrypted to that one person, over LoRa or the backbone; a relay or a listener on the air sees nothing. The @allow lines are cut out first.
    4. 
    
  4. Not on the list: one short answer. "Locked" (a few bytes) or, with @locked hidden, the ordinary "Not found". Pictures in a locked folder answer the same way.
    5. 
    
  5. The reader's copy stays private. The browser keeps a locked page only in memory (not in the offline cache), and marks it 🔒 in the address bar with how many may read it.
    6.
