Må:rse Mesh Lab

Four ways to run a LoRa mesh, on the same map, with the same people sending the same messages. Watch a message travel, break things, and see why each design wins or loses.

Scaling lab

Each chart sweeps one thing and runs all four designs at every point. These are the patterns behind the scenarios. Press Run on a chart (it takes a few seconds).

Må:rse is open source (MIT or Apache-2.0). This lab is a simplified model for building intuition; the project's own maarse-sim runs the real router code. github.com/trixxor/maarse
