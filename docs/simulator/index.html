This is a simplified model for building intuition, not a radio simulator. Links fail more often the farther apart two nodes are. Packets sent at the same time can collide, and a busy channel loses more. Each protocol follows its main routing rule, as described under the scenario. The absolute numbers are indicative only. The project's own Rust simulator (maarse-sim) runs the real Må:rse router code; see the README for its results.
