Må:rse handbook

Text, pictures and voice between cheap radios, with no mobile network and no central server.

TL;DR

Må:rse is a mesh network. Small LoRa radios pass messages to each other over several kilometres. Where there is internet, hosts join the radio areas into one network, so the same address and encryption work everywhere.

Status: working prototype, version 0.9. Latest release v0.9.10. Not measured in the field yet, and the cryptography has not been reviewed by outsiders. What works today →

How to read this handbook

Every page starts with a TL;DR box: what the thing is, why it exists, and its advantages and drawbacks. If that is enough, stop there.

Below it, the page explains the idea in plain words, with interactive figures you can play with. Marked sections called Deep dive go into byte layouts, constants, timers and the reasons behind each choice. They are hidden by default so the first read stays simple. Use Deep dives: hidden in the top bar to show them everywhere, or the link on each page to show them there.

Status labels

Claims in this handbook carry a label that says how far they have been proven. A feature that only works in a simulator is never described as working on hardware.

LabelMeaning
releasedIn a published release, v0.9.10 or earlier.
working copyBuilt and tested in the repository, but not in a release yet.
simulatedMeasured in maarse-sim, which runs the real router code on virtual nodes. Not measured in the air.
bench-testedRun on real boards on a desk.
field-testedMeasured outdoors with real distances. Nothing carries this label yet.
designed, not builtWritten down, no code.
shelvedConsidered and parked on purpose.
rejected (measured)Tried and found not worth it. The numbers are kept.
Honest status

Må:rse runs on two boards on a desk, a PC host, a web client and an Android app. Meshtastic, MeshCore and Reticulum are mature projects with real users. Må:rse is an attempt to combine their best ideas, and it has no field data yet.
