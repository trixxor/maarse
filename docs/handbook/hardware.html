Radio boards

The four boards Må:rse runs on, and what each can do.

TL;DR

What: Må:rse runs on four LoRa boards with an SX1262 radio: Heltec V4 (ESP32-S3 with a display), Seeed XIAO nRF52840 with a Wio-SX1262, Seeed XIAO ESP32-S3 and the RAK WisMesh Tag. They cost roughly €20–40 and connect to a phone over Bluetooth or USB.

Why: Choosing the board is choosing a connection. Heltec V4 gives a display and Wi-Fi. The nRF52840 boards are the low-power choice with Bluetooth and USB.

Strengths

  • Same firmware logic on all boards, written once in Rust
  • Signed firmware updates over USB, Bluetooth and Wi-Fi
  • Battery measurement and energy-aware forwarding on the boards that have a divider
  • A web flasher: no tools to install

Good to know

  • Only the Heltec V4 and the XIAO nRF52840 have been run on a desk bench; the other two build but are not flashed
  • ESP32 boards have almost no stack to spare when a host is attached
  • Bluetooth on ESP32 boards is built in but not tried on hardware

bench-tested Heltec V4 and XIAO nRF52840. Others build only. Not field-tested.

Battery and measuring it

The firmware measures the battery voltage every 60 seconds (the average of eight measurements) and uses it for energy-aware forwarding. The nRF52840 also sees USB power. The ESP32 boards report USB power as unknown.

The ESP32 stack is tight

With a host attached the Heltec firmware has under 100 bytes of stack to spare. After adding a static or deeper calls, run tools/stack_probe.py before flashing.

If Wi-Fi starting crashes the board twice in a row, it is skipped until the board has run stably for 60 s. Wi-Fi starts 10 s after boot so USB is always reachable first.
