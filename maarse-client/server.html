MeshCore gateway

The Heltec V4 radio gateway connects here over TLS, and the local radio worker drives the MeshCore radio. Only people on the list below can use MeshCore from the apps. Grants are kept in meshcore-access.txt in the data folder.

Allowed people by Må:rse person address (32 hex characters).

Gateway setup port, name and token; the server makes its own certificates

The server runs its own small certificate authority for the gateway. The gateway trusts that authority and nothing else, so no certificate files need to be copied. Forward the gateway port in the router to this server. Saving creates the certificate and restarts the server.

Pair a gateway

Save the port and name above first. Create a pairing code, then paste it into the gateway's setup page (Pairing code) together with its Wi-Fi. The code works once and for ten minutes. The gateway then contacts this server, gets its own token and restarts. A new pairing replaces the old gateway's token.

Manual setup without a pairing code

Instead of a pairing code you can enter these in the gateway's setup page (Backbone connection): the name, the port, the token and the authority certificate below. The authority only has to be entered once; it stays the same when the server certificate is renewed.

Connections now

Every link: backbone peers (in and out), modems and other links. Incoming links are limited per address and rate limited; a peer sending junk or flooding is banned for a while. "Close" drops a link (it may come back); "Block" closes it and keeps its address out.

Block list

IP addresses, networks (e.g. 203.0.113.0/24) and node addresses (32 hex) that are never accepted. Kept in blocked.txt; takes effect at once.

Temporary bans

Addresses that sent too many invalid packets or kept going over the rate limit.

Settings

Saved in settings.txt in the data folder and used at every start. Saving restarts the server (a few seconds; you stay logged in). Options given on the command line or in the start script also apply and win over these.
