# Må:rse brugerguide (dansk)

Korte sider i almindeligt sprog, én for hver ting, du kan gøre. Hver side
siger, hvad det er, hvordan du gør på Android-appen og i webklienten, viser et
eksempel og linker til
[Danmarkssimulatoren](https://trixxor.github.io/maarse/denmark/), så du kan se
det ske.

Siderne er oversat fra [den engelske guide](../README.md). Hvis de to er
forskellige, er den engelske den rigtige. Ordene i appen står, som de står i
den danske app (Indstillinger, Noder, Chats ...).

| Backup og gendannelse | planlagt |

**Sprog.** Appen og webklienten følger din enheds sprog og kan skiftes i
**Indstillinger** (Automatisk, English, Dansk). Mere: [Sprog](../../i18n.md).
